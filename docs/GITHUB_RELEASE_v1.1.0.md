## ✨ Destaques da Versão 1.1.0

### 🏛️ Menu Unificado
- **Localização Oficial:** Vinculação ao menu **Complementos → Ferramentas Geo** do QGIS.

### ⚙️ Pipeline Completo de Vetorização e Otimização
- **Processamento Multi-Core:** Scripts de pipeline para vetorização multi-CPU, criação de índices espaciais, mesclagem dinâmica de atributos e compressão otimizada de shapefiles para upload.
- **Robustez na Interface:** Melhorias de feedback visual no console de log escuro, barra de progresso e persistência de parâmetros.
- **Empacotamento Centralizado:** Pacote `geopipe_qgis_v1.1.0.zip` (497 KB) gerado na pasta `plugins_zip/`.

---

## 📦 Instalação e Atualização

1. No QGIS: **Plugins** → **Gerenciar e Instalar Plugins...** → **Instalar a partir do ZIP**.
2. Selecione o arquivo `geopipe_qgis_v1.1.0.zip`.
3. Clique em **Instalar plugin**.
